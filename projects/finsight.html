FinSight: RAG system and AI agent over 100 annual reports

TypePersonal project
WhenOct – Nov 2026
ContextSolo, end to end
View code on GitHub

Overview

An AI system for extracting financial insights from 100 corporate annual reports. It analyses complex filings, synthesises information across reports, and answers with page-level citations, and it says so when the answer isn't in the filings instead of making one up. For questions about figures, a LangGraph agent queries a SQL table of key financial figures, searches the filings, or combines both.

75% → 100%accuracy on a hand-written set of hard questions after adding hybrid search and query rewriting
58,670chunks indexed from 100 reports in ChromaDB
2 cloudsdeployed on Google Cloud Run and Azure Container Apps

How it works

  1. IngestPage-aware, table-preserving chunking with company metadata.
  2. RetrieveEmbeddings + BM25 keyword search, fused with Reciprocal Rank Fusion, plus LLM query rewriting.
  3. AnswerGemini writes the answer with page citations, or refuses when the reports don't cover it.
  4. RouteA LangGraph agent picks read-only SQL or document search, with multi-turn memory.
  5. EvaluateLLM-as-judge on synthetic and hand-written sets; every step traced in Langfuse.
  6. DeployFastAPI in Docker on Cloud Run and Azure, with canary rollout and CI in GitHub Actions.

What I did

  • Built the full RAG pipeline in Python with the Gemini API: answers cite the exact report page, and the system explicitly refuses when information is missing, to reduce hallucinations.
  • Ingestion keeps tables intact and chunks by page, then enriches every chunk with metadata so retrieval can be filtered by company.
  • Hybrid retrieval (sentence-transformer embeddings + BM25, fused with Reciprocal Rank Fusion) and LLM-based query rewriting raised accuracy on the hard question set from 75% to 100%.
  • An evaluation framework scores retrieval and answers separately, with LLM-as-judge. Langfuse traces every step with latency and token usage, and links evaluation scores to traces for failure analysis.
  • Extended into an agent: key financial figures from all reports are extracted into SQL with structured LLM output (Pydantic), and a tool-calling LangGraph agent chooses between SQL queries and document retrieval. Tool choice and answer correctness are evaluated too.
  • Shipped as a REST API (FastAPI, Docker) on Google Cloud Run and Azure Container Apps, with managed identity and secrets, a canary rollout with instant rollback between revisions, unit tests, and CI in GitHub Actions.
