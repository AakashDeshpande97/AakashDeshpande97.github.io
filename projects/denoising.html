Self-supervised denoising of microscopic images

TypeCourse project
WhenMay – Jul 2024
ContextUniversity of Siegen
View code on GitHubDeployment case study

Overview

Can a network clean up a microscope image without ever seeing a clean example? I implemented Zero-Shot Noise2Noise (ZS-N2N), a small CNN trained from scratch on each noisy image, and compared it with classical filters across three noise types. The comparison then became a deployed web service.

~20Kparameters in the two-layer ZS-N2N network
33.88 dBPSNR on Poisson noise, within 0.3 dB of BM3D
0training images or pretrained weights needed

How it works

  1. Add noiseGaussian, Poisson and uniform noise on microscope images.
  2. Classical filtersMedian, Wiener and BM3D as baselines.
  3. ZS-N2NA 2-layer CNN trained per image, no external data.
  4. MeasurePSNR for every method and noise type.
  5. DeployFastAPI + Docker on Cloud Run and GKE, with CI/CD.

What I did

PSNR in dB (higher is better)

NoiseMedianWienerBM3DZS-N2N
Gaussian27.0925.5129.6428.75
Poisson27.9226.0234.1533.88
Uniform28.9529.6333.3933.03
  • ZS-N2N beat Median and Wiener filtering on every noise type and came within about 1 dB of BM3D, while learning only from the noisy image itself.
  • Wrapped the full comparison in a FastAPI service, containerised with Docker and deployed to Google Cloud Run through Artifact Registry as a public REST API.
  • A GitHub Actions pipeline builds, pushes and deploys on every code change, with no manual steps. The same image also runs on a GKE Autopilot cluster.
